Chào mừng đến với Giáo Trình Raylib Odin!

Hãy chọn một chương ở menu bên trái để bắt đầu đọc. Toàn bộ tài liệu đều hỗ trợ highlight code và giao diện tối mượt mà bảo vệ mắt.

Lưu ý: Để trình duyệt có quyền đọc các file .md trong máy tính, bạn cần chạy trang web này thông qua một local server (ví dụ như Live Server của VSCode, hoặc gõ lệnh python -m http.server trong terminal).
